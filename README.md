# 🌟 3D 어휘 학습 탐험 게임

Three.js 기반의 웹 3D 교육용 학습 게임입니다. 귀여운 동물 영웅(탐험가 고양이, 로보트 강아지, 마법사 토끼)과 함께 아름다운 3차원 섬을 탐험하며 스테이지별 어휘 퀴즈를 풀고 단어를 수집해보세요!

## 🎮 게임 특징

- **3개 스테이지 테마 & 동적 환경 변화**
  - **스테이지 1 (상쾌한 아침)**: 쨍하고 화사한 아침 푸른 하늘 아래 알록달록한 주택 마을, 수련 호수, 깃발과 수영 가능한 광장 분수대.
  - **스테이지 2 (학교와 대운동장)**: 한낮의 3D 입체 태양이 떠 있는 하늘 아래 시계탑과 태극기 게양대가 있는 초등학교 본관, 야외 수돗가, 육상 트랙 및 축구/농구 경기장, 철봉 및 뜀틀 코스.
  - **스테이지 3 (노을빛 놀이터 테마)**: 따뜻한 석양빛 하늘 아래 오리배가 떠 있는 호수와 무지개 분수, 회전하는 회전목마, 대형 미끄럼틀 요새, 2인용 그네와 시소, 정글짐, 통통 튀는 무지개 점핑 디스크.
- **풍부한 상호작용 & 액션**
  - 점프, 수영(마을 호수 및 광장 분수대 수영 모션 및 물장구 파동), 6종 캐릭터 이모트 표현.
  - 문제 카드 수집 및 인터랙티브 어휘 퀴즈 풀이.
  - 배경음악(BGM) 음원 재생 및 전환.

## 🚀 실행 방법

웹 서버 환경 또는 로컬 브라우저에서 `index.html` 파일을 직접 열어 플레이할 수 있습니다.
