📄 학생 기록 상세

🛡️ Supabase 데이터베이스 삭제·조회 권한(RLS) 설정

학생 기록 삭제가 차단되는 원인은 Supabase 클라우드 데이터베이스의 보안 정책(RLS) 때문입니다.
아래 SQL을 복사하신 후, [Supabase SQL Editor 열기]에서 붙여넣고 Run(실행)을 한 번만 눌러주시면 영구적으로 삭제 및 조회가 정상 작동합니다. 

-- 1. 게임 기록 조회(SELECT) 권한 허용
ALTER TABLE public.game_records ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "Allow public read access on game_records" ON public.game_records;
CREATE POLICY "Allow public read access on game_records" ON public.game_records FOR SELECT TO public USING (true);

-- 2. 게임 기록 삭제(DELETE) 권한 허용
DROP POLICY IF EXISTS "Allow public delete game_records" ON public.game_records;
CREATE POLICY "Allow public delete game_records" ON public.game_records FOR DELETE TO public USING (true);
